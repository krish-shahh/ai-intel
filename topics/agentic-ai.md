Agentic AI covers systems where LLMs plan and act over multiple steps with tools, instead of answering a single prompt. This page tracks agent frameworks, coding agents, and the shift from chat assistants to autonomous workflows.

## Notes

- **2026-07-07** JADEPUFFER (Sysdig, July 1): first fully documented autonomous AI ransomware. An LLM agent exploited CVE-2025-3248 (unauth RCE in Langflow), pivoted laterally, escalated privileges, and encrypted 1,342 Nacos service configs — then discarded the key, leaving data unrecoverable even for victims who paid. Tell: LLM-generated one-liners contain natural-language commentary explaining each action; human operators don't annotate throwaway code. Skill floor for ransomware operations is now the cost of running an agent. [Sysdig](https://www.sysdig.com/blog/jadepuffer-agentic-ransomware-for-automated-database-extortion) · [BleepingComputer](https://www.bleepingcomputer.com/news/security/jadepuffer-ransomware-used-ai-agent-to-automate-entire-attack/)
