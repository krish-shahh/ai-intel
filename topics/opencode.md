OpenCode is an open-source, model-agnostic terminal coding agent built by Anomaly, the team behind SST. This page tracks its releases, provider support, and the products built on top of it.

## Notes

- **2026-06-22** v1.17.8: faster session timeline loading, MCP tool schema validation fixes, Cloudflare AI Gateway support. [GitHub releases](https://github.com/opencode-ai/opencode/releases)

- **2026-06-12** v1.17.4: adds `cwd` support for local MCP servers; fixes Gemini tool schemas, content-filtered model responses, and snapshot creation performance on large repos. [GitHub](https://github.com/anomalyco/opencode/releases)
- **2026-06-10** v1.17.0 major release: faster file search via fff-backed tools, WSL desktop support, improved MCP capabilities and reasoning model support, significant UI refinements across desktop and TUI. [GitHub](https://github.com/anomalyco/opencode/releases)
- **2026-06-06** PewDiePie's Odysseus project, a self-hosted personal AI workspace built on OpenCode, hit 44K GitHub stars in under a week. [[swyx]] called it a vibe shift moment for consumer-facing local AI. ([GitHub](https://github.com/pewdiepie-archdaemon/odysseus))
- **2026-06** OpenCode sitting at 162K stars, supports 75+ providers. Increasingly used as underlying infrastructure for personal AI workspace products.
- **2026-06-06** Latest updates include adaptive reasoning controls for Anthropic Opus 4.7+ and WebSocket transport for OpenAI responses. [GitHub](https://github.com/opencode-ai/opencode)
