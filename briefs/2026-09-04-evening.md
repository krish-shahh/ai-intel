## Models & research

### GPT-6 Astra
**Claim:** [OpenAI](https://openai.com/index/gpt-6-astra/) (primary) says Astra is state of the art on computer use, browsing, software engineering, cybersecurity, and science, citing scores of 98% on FrontierMath Tier 4, 99.9% on ARC-AGI-3, and 100% on ExploitBench.
**Evidence:** [Artificial Analysis](https://artificialanalysis.ai/articles/benchmarking-gpt-6-astra) (independent) scores it 61 on their Intelligence Index, tied with the outgoing GPT-5.6 Sol and xAI's Grok 4.6, five points behind Claude Fable 5.1's 66. It does better relatively on their Coding Agent Index, matching Fable 5 at under half the cost, and cuts the hallucination rate from 92% to 51%.
**Caveat:** Near-saturated scores (99.9%, 100%) say more about the benchmark's ceiling than a real edge over competitors, and a 51% hallucination rate, while improved, still means roughly half of probed answers come back wrong or fabricated. Pricing also jumped 2.5x per token ($10/$50 per million vs. $4/$20 for the prior model).
**Worth your time:** Skim.

## Tools worth touching

### Claude Code v2.1.260
- Does: adds a live Diff Panel (`/diff`) showing uncommitted changes beside the conversation, cache-miss diagnostics in `/cost` and the status line, and `/reload-plugins` for headless sessions.
- Why now: the cache-miss diagnostics finally answer what's usually guesswork — whether a prompt-cache write got invalidated by changed tool defs, a changed system prompt, or just idling past the TTL.
- Try if: you run long agent sessions and want to see edits before committing, or you're chasing unexplained cost spikes.
- Skip if: nothing about your current setup is bothering you — this is additive, not a fix for a break.
- Links: [changelog](https://code.claude.com/docs/en/changelog)

### Codex CLI v0.153.0
- Does: adds undo/redo in vim mode (`u` / `Ctrl+R`) that preserves drafts and attachments, plus a plugin CLI to list, install, and remove plugins from remote marketplaces.
- Why now: closes a rough edge for anyone using Codex's vim-mode composer, and plugin management no longer needs manual file editing.
- Try if: you use Codex CLI's TUI daily, especially in vim mode.
- Skip if: you don't use Codex or don't use vim mode.
- Links: [release notes](https://github.com/openai/codex/releases/tag/rust-v0.153.0)
