## Tools worth touching

### PageIndex
- Does: vectorless, reasoning-based document indexing for RAG. Builds a navigable tree structure instead of chunking into embeddings.
- Why now: trending on GitHub today (1,100+ stars), part of a broader move away from embedding-similarity RAG toward LLM-reasoning-based retrieval.
- Try if: your RAG pipeline struggles with long structured documents (contracts, manuals) where chunk boundaries break meaning.
- Skip if: you're doing simple short-document QA where standard vector RAG already works fine.
- Links: [GitHub](https://github.com/VectifyAI/PageIndex) (repo)

### context-mode
- Does: a context-window optimizer for coding agents that claims to cut tool-output tokens by up to 98%.
- Why now: trending today as agent harnesses hit context limits faster with larger codebases and longer tool-call chains.
- Try if: your coding agent is burning context budget on verbose tool output (test logs, file listings) rather than reasoning.
- Skip if: you want the 98% figure verified first. That's the project's own claim, not yet independently benchmarked.
- Links: [GitHub](https://github.com/mksglu/context-mode) (repo)
