TL;DR
OpenAI and Oracle announced that enterprise customers can route OpenAI models and Codex through existing Oracle UCM credits. Simon Willison shipped datasette 1.0a33 with two security patches.

## Tools & dev

- [[simonw]] released datasette 1.0a33 (June 11, 15:26 UTC): patches a SQL injection flaw in identifier escaping involving bracket characters and an open redirect via backslash normalization; also adds stored query edit/delete from the web UI and extends `?_extra=` to row and query pages. [Release](https://github.com/simonw/datasette/releases/tag/1.0a33)

## Other

- OpenAI and Oracle announced OCI enterprise customers can apply existing Oracle UCM cloud credits toward OpenAI models and [[codex]], no separate procurement needed; rollout in coming weeks. [openai.com](https://openai.com/index/openai-on-oracle-cloud/)

- Malwarebytes survey (1,500 adults, US/EU): 85% say they can no longer tell AI-generated content from real, up from 66% in 2025; half reported an AI-driven scam encounter in the past year. [Help Net Security](https://www.helpnetsecurity.com/2026/06/11/ai-scams-deepfakes-survey/)
