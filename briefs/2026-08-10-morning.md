## The signal

1. **Claude Code defaults to auto mode on August 14**
   What happened: Anthropic announced on August 9 that auto mode becomes the default for Pro, Max, and Team plans on August 14; Claude Code will run without per-action approvals unless an action is irreversible, destructive, or targets outside the user's environment; internal data shows 97% of manual approval prompts were approved without review, and a 1,053-user study found auto mode caught 89% of harmful actions vs 13.6% for human reviewers; the safety classifier is now free (previously required extra compute billing).
   Why it matters: Opt-out changes what shipped code your agent can modify by default -- if your team relies on the per-prompt gate to catch surprises, you have four days to decide whether to pin back to manual mode before Aug 14.
   Confidence: Confirmed
   Sources: [Anthropic blog](https://claude.com/blog/auto-mode-default-in-claude-code) (primary) · [TechCrunch](https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/) (independent) · [Simon Willison](https://simonwillison.net/2026/Aug/8/auto-mode/) (independent) · [The Register](https://www.theregister.com/ai-and-ml/2026/08/10/claude-code-puts-auto-mode-in-the-drivers-seat/5285326) (independent)

2. **Meta releases Muse Glimmer 30B: open-weight local agent model**
   What happened: Meta published Muse Glimmer today on Hugging Face under Apache 2.0 license; it is a 30B-parameter model distilled from Muse Spark 1.2, designed for always-on local agent workflows including function calling, local coding, and LLM-as-a-judge evaluation; runs on a single consumer GPU.
   Why it matters: Meta now has a full agentic stack in the open -- Muse Code (terminal agent), Muse Spark 1.2 (frontier), and Muse Glimmer (local edge); Apache 2.0 removes the licensing friction that slowed adoption of prior Meta models.
   Confidence: Confirmed
   Sources: [Meta AI Research blog](https://research.meta.ai/blog/introducing-muse-glimmer-open-agentic-model) (primary) · [Hugging Face](https://huggingface.co/meta-models/Muse-Glimmer-30B) (primary) · [Bloomberg](https://www.bloomberg.com/news/articles/2026-08-10/meta-releases-muse-glimmer-ai-model-people-can-run-on-their-laptop) (independent) · [Phoronix](https://www.phoronix.com/news/Meta-Muse-Glimmer) (independent)
