## Tools worth touching

### OpenCode
- Does: open-source, model-agnostic terminal coding agent from Anomaly, self-hostable across 75+ providers
- Why now: shipped v1.18.30 today with a system prompt tuned for GPT-6 "Astra," a Bedrock DeepSeek model-ID fix, and updated Azure/OpenAI provider SDKs
- Try if: you run coding agents across multiple model providers and want same-day support when a new frontier model lands
- Skip if: you're already committed to a single-vendor agent like Claude Code or Codex and don't need provider flexibility
- Links: [Release notes](https://github.com/anomalyco/opencode/releases)
