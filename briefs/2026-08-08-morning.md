## The signal

1. **OpenAI pauses Astra development after internal evals hit Critical cybersecurity threshold**
   What happened: On August 7, OpenAI disclosed that Astra's internal evaluations show the model can identify and develop novel zero-day exploits against hardened critical systems without human intervention, meeting the Critical threshold under its Preparedness Framework. No prior model, including GPT-5.6 Sol, has triggered that level. OpenAI paused some internal Astra work, tightened security controls for testing, and said it will bring in government agencies and outside safety organizations before any release.
   Why it matters: This is the first self-imposed development pause triggered by a company's own safety framework rather than an external regulator; if Critical becomes the new baseline for frontier models, the pre-release review process now has real teeth.
   Confidence: Confirmed

## Models & research

### Prime Agent (PrimeIntellect)
**Claim:** Open-source (MIT) self-improving RLM coding harness released Aug 6; 95.5% on ARC-AGI-3 when paired with Claude Opus 5, above the stated 95.4% human-expert baseline.
**Evidence:** Primary blog post and GitHub repo are public. ARC-AGI-3 result is company-reported. No independent replication confirmed. The 95.4% human-expert baseline on ARC-AGI-3 is PrimeIntellect's own stated figure.
**Caveat:** Benchmark is self-administered; margin over human baseline is 0.1 points. Architecture relies on a persistent IPython kernel and sub-agent spawning via code rather than tool schemas, which is interesting but unproven at production scale.
**Worth your time:** Read (if you build coding agents; the RLM + persistent kernel design has real engineering merit regardless of the ARC-AGI-3 number)
Sources: [PrimeIntellect blog](https://www.primeintellect.ai/blog/prime-agent) (primary) · [GitHub](https://github.com/PrimeIntellect-ai/prime-agent) · [MarkTechPost](https://www.marktechpost.com/2026/08/06/prime-intellect-releases-prime-agent/) (independent)

## Tools worth touching

### prime-agent (PrimeIntellect)
- Does: Self-improving RLM agent for coding and long-running autonomous tasks; subagents are function calls inside a persistent IPython kernel; harness can refine its own supplemental state without touching the base system prompt
- Why now: Trending #1 on GitHub today (+2,483 stars); MIT license; native sub-agent spawn that returns results as Python objects cuts the context-threading boilerplate common in LangChain-style pipelines
- Try if: Building a coding agent that needs durable state and parallel sub-task dispatch without glue code
- Skip if: You need a stable production harness today; this is research-grade and the `/refine` self-edit loop is explicitly experimental
- Links: [GitHub](https://github.com/PrimeIntellect-ai/prime-agent) · [blog](https://www.primeintellect.ai/blog/prime-agent)

### book-to-skill (virgiliojr94)
- Does: Converts technical book PDFs into Claude Code skill files; chunking and context extraction handled automatically
- Why now: Trending today (+660 stars on Python trending); directly usable with the Claude Code skills system; no other tool fills this specific gap
- Try if: You have team-specific docs or books you want Claude Code to reference during sessions
- Skip if: Your knowledge base is already in markdown or you need dynamic retrieval rather than static skill injection
- Links: [GitHub](https://github.com/virgiliojr94/book-to-skill)

### Claude Code self-hosted environments (beta)
- Does: Runs Claude Code agent sessions on customer-controlled compute (Team/Enterprise); sessions start from web, mobile, desktop, or a routine and execute on your own runners
- Why now: Public beta opened Aug 6; resolves the blocker for teams that cannot send code context to Anthropic-hosted infra due to compliance or network policy
- Try if: Your org has strict data residency requirements or your agents need direct access to internal services not reachable from cloud
- Skip if: You're on the free or Pro plan; option is Enterprise/Team only
- Links: [Anthropic blog](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute) · [changelog](https://releasebot.io/updates/anthropic/claude-code)
