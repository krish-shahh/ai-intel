TL;DR
Claude Fable 5 (Anthropic's first public Mythos-class model) launched June 9 and is being rapidly plumbed into the toolchain; two more Claude Code patches landed today, including an enterprise model-lockdown setting. OpenAI's TanStack-breach cert revocation deadline hits today for macOS users.

## Models & research

- Anthropic's [[model-releases]] milestone: [[claude-code]] stack now ships with Claude Fable 5 (released June 9), a Mythos-class model with 1M context and 128k output, scoring 95% on SWE-bench Verified at $10/$50 per million tokens. Free on Pro/Max/Team through June 22, then shifts to usage credits. [Anthropic](https://www.anthropic.com/news/claude-fable-5-mythos-5) · [TechCrunch](https://techcrunch.com/2026/06/09/anthropic-released-claude-fable-5-its-most-powerful-model-publicly-days-after-warning-ai-is-getting-too-dangerous/)

[OpenAI](https://openai.com/index/our-response-to-the-tanstack-npm-supply-chain-attack/) · [9to5Mac](https://9to5mac.com/2026/06/02/psa-a-security-breach-means-you-must-update-the-chatgpt-mac-app/)

## Tools & dev

- [[claude-code]] v2.1.175 (today, 04:23 UTC) adds `enforceAvailableModels` managed setting — when on, the `availableModels` allowlist constrains the Default model and user/project settings can't widen a managed list. [GitHub](https://github.com/anthropics/claude-code/releases)
- [[claude-code]] v2.1.174 (today, 01:16 UTC) adds usage attribution breakdown (cache misses, long context, subagents) to the Account & usage dialog; fixes enterprise Fable 5 credits banner and Bedrock GovCloud region handling. [GitHub](https://github.com/anthropics/claude-code/releases)
- [[claude-code]] v2.1.172 (June 10) enables nested sub-agents: agents can now spawn their own sub-agents up to 5 levels deep, with Bedrock reading AWS region from `~/.aws` config when `AWS_REGION` isn't set. [GitHub](https://github.com/anthropics/claude-code/releases)

## OSS

- [[opencode]] v1.17.0 (June 10) was a bigger release: faster file search via fff-backed tools, WSL desktop support, improved MCP capabilities, and significant UI refinements across desktop and TUI. [GitHub](https://github.com/anomalyco/opencode/releases)
