## Tools worth touching

### cloudflare/security-audit-skill
- Does: a Claude Code / agent skill that runs a six-phase security audit (recon, coverage-led hunting, candidate validation, structured output, independent verification, reporting) and sorts findings into confirmed / needs_validation / rejected against a JSON schema.
- Why now: it's Cloudflare's own internal vulnerability-discovery harness open-sourced, trending on GitHub today with 26.1k stars and active issues/PRs.
- Try if: you want a repeatable, machine-checkable security pass on a codebase instead of a one-off prompt — the README notes repeated runs roughly double coverage versus a single pass.
- Skip if: you don't have an OS-level sandbox for executing target code; without it the skill downgrades leads to needs_validation rather than confirming them.
- Links: [repo](https://github.com/cloudflare/security-audit-skill)

### addyosmani/agent-skills
- Does: packages a full spec-to-ship engineering workflow (25 skills across Define/Plan/Build/Verify/Review/Ship, 9 slash commands, 4 reviewer personas) as plain-Markdown skills for coding agents.
- Why now: trending today at ~102.8k stars; works across Claude Code, Cursor, Gemini CLI, Codex, Copilot, Windsurf, and OpenCode since skills are just instruction files.
- Try if: you want structured TDD/spec/review discipline enforced on an agent without hand-rolling your own prompts.
- Skip if: you only need a single skill — installing one via npx drops the shared references/ directory the checklists depend on; use a full-repo install instead.
- Links: [repo](https://github.com/addyosmani/agent-skills)
