## Tools worth touching

### NousResearch/hermes-agent
- Does: open-source (MIT) agent framework that writes reusable skills from completed tasks, persists memory across sessions, and reaches users over 14+ messaging platforms (CLI, Telegram, Slack, email, and more)
- Why now: v0.19.1 tagged early August; 224K GitHub stars with 468 gained today; Nous Research closing a $75M raise at a $1.5B valuation, signaling sustained maintenance investment
- Try if: you are building long-running agents that need to improve on a task type over time without explicit re-prompting
- Skip if: your workflow is one-shot or stateless and you don't want persistent memory overhead
- Links: [repo](https://github.com/NousResearch/hermes-agent) · [funding](https://techcrunch.com/2026/07/13/hermes-agent-maker-nous-research-in-talks-for-new-funding-at-1-5b-valuation/)

### Panniantong/Agent-Reach
- Does: CLI (Python, zero API fees) that gives agents read and search access to Twitter, Reddit, YouTube, GitHub, Bilibili, and XiaoHongShu using session/cookie auth with automatic failover when one path is blocked
- Why now: 659 stars gained today (64K total); the zero-cost, zero-quota angle is increasingly practical now that most hosted social APIs have tightened or paywalled access
- Try if: you need agents to ingest community or social data without managing API quotas or paying per-call
- Skip if: you need verified/official data or write access to any of those platforms
- Links: [repo](https://github.com/Panniantong/Agent-Reach) · [trendshift](https://trendshift.io/repositories/24387)
