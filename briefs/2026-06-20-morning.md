## Tools & dev

- [[claude-code]] v2.1.183 (June 19): auto mode now blocks destructive git ops (git reset --hard, git checkout -- ., git clean -fd, git stash drop) when you didn't ask to discard local work; git commit --amend blocked unless the agent made the commit this session; terraform/pulumi/cdk destroy gated unless you explicitly named the stack. Adds /config --help and a new attribution.sessionUrl setting to omit session links from commits. Drops CODEX_HOME and GEMINI_HOME env vars and the gemini-extension.json model slot. ## OSS

- `palmier-io/palmier-pro` (+904 stars today, 2,513 total): open source macOS video editor built for AI. Connect Claude via MCP and it can read your project, cut clips, reorder the timeline, and generate new footage with Seedance, Kling, or Nano Banana Pro in-place. Swift, requires macOS 26 (Tahoe). Free to download, no login required for editing. YC-backed.
