1. **Anthropic ships Claude Opus 5 at half the price of Fable 5**
   What happened: Anthropic released Claude Opus 5 on July 24; priced at $5/$25 per million input/output tokens (same as Opus 4.8, half of Fable 5's $10/$50); new effort-toggle (low/medium/high) exposes per-request cost-capability tradeoffs; available immediately on API, Bedrock, Google Cloud, Microsoft Foundry, Claude.ai, and Claude Code; now the default on Claude Max and strongest on Claude Pro.

## Models & research

### Claude Opus 5
**Claim:** Near-Fable-5 intelligence at $5/$25 per million tokens; beats Opus 4.8 on agentic coding, computer use, and multidisciplinary reasoning; effort-toggle (low/medium/high) gives per-call quality-cost control.
**Evidence:** Anthropic-published benchmark comparisons vs. Opus 4.8; available immediately for API evaluation. No independent third-party eval published at time of this brief.
**Caveat:** "Near Fable 5" is not quantified in the release materials. Effort-toggle behavior under sustained reasoning load is uncharacterized externally.
**Worth your time:** Read -- directly affects cost modeling for Opus-class agentic workloads. [Anthropic](https://www.anthropic.com/news/claude-opus-5) · [9to5Mac](https://9to5mac.com/2026/07/24/anthropic-upgrades-claude-with-new-opus-5-model-details-here/)

### Kimi K3 open-weights escalation (Lambert analysis)
**Claim:** Open-to-closed gap is now 3-5 months, not 6-9; K3 at 2.8T parameters is the clearest evidence yet; [[natolambert]] frames this as a structural shift, not an anomaly.
**Evidence:** Artificial Analysis Intelligence Index rankings; Lambert's analysis on Interconnects. No community benchmarking on the actual weights yet -- that begins July 27.
**Caveat:** The gap estimate is qualitative. Numbers will look different once the community gets the weights and runs independent evals.
**Worth your time:** Read if you are making model selection decisions or planning open-weight deployments. [interconnects.ai](https://www.interconnects.ai/p/kimi-k3-the-open-weights-escalation)

## Tools worth touching

### ego-lite (citrolabs)
- Does: Shared-state browser for humans and AI agents; agents inherit your existing cookies, logins, and bookmarks without credential passing
- Why now: Hit #1 on GitHub trending July 24; team's own benchmarks show 2.5x faster than Vercel's agent-browser on complex web automation with fewer tokens; MIT license
- Try if: You're automating logged-in web workflows with Claude Code or similar agents and want agents to share your existing session state directly
- Skip if: Automation targets unauthenticated pages, or you don't want agents inheriting your browser session
- Links: [github.com/citrolabs/ego-lite](https://github.com/citrolabs/ego-lite) · [runtimewire](https://runtimewire.com/article/ego-lite-reaches-github-trending-1-marking-a-surge-in-ai-agent-tool-interest)

### alibaba/open-code-review
- Does: Hybrid deterministic + LLM-agent code review CLI; reads Git diffs, lets the agent read full file contents and search the codebase, outputs line-level comments with built-in security rules (NPE, thread safety, XSS, SQL injection); OpenAI and Anthropic compatible
- Why now: 1,066 GitHub stars today; was Alibaba's internal code review tool for tens of thousands of developers, now MIT-licensed and open
- Try if: You want automated code review that goes deeper than diff-surface feedback; good complement to Claude Code for pre-merge checks
- Skip if: You need ready-made GitHub Actions integration -- check the repo for CI workflow status before committing
- Links: [github.com/alibaba/open-code-review](https://github.com/alibaba/open-code-review)
