## The signal

1. **Anthropic ships Claude Opus 5 -- near-flagship intelligence at half the price**
   What happened: Anthropic released Claude Opus 5 on July 24, available immediately on the API, Bedrock, Google Cloud, Microsoft Foundry, Claude.ai, Claude Code, and Cowork; priced at $5/$25 per million input/output tokens (unchanged from Opus 4.8, half of Fable 5's $10/$50); adds an effort-toggle (low/medium/high) that trades cost against capability per request.
   Why it matters: A near-Fable-5-quality model at Opus pricing changes the cost math for agentic workloads -- the effort-toggle is also a new interface primitive that no other frontier API exposes yet.
   Confidence: Confirmed
   Sources: [Anthropic](https://www.anthropic.com/news/claude-opus-5) (primary) · [TechCrunch](https://techcrunch.com/2026/07/24/anthropic-launches-opus-5/) (independent) · [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-24/anthropic-unveils-more-cost-efficient-model-for-everyday-tasks) (independent) · [Fortune](https://fortune.com/2026/07/24/anthropic-debuts-claude-opus-5-with-feature-that-lets-users-toggle-between-cost-and-capability/) (independent)

## Models & research

### Claude Opus 5
**Claim:** Approaches Fable 5 performance at half the price ($5/$25 per million tokens); beats Opus 4.8 on agentic coding, computer use, novel problem solving, and multidisciplinary reasoning; new effort-toggle (low/medium/high) exposes per-request cost-capability tradeoffs.
**Evidence:** Anthropic-published benchmark comparisons vs. Opus 4.8; available immediately for API evaluation. No independent third-party eval published yet.
**Caveat:** "Approaches Fable 5" is not quantified in released materials; effort-toggle behavior on reasoning-heavy tasks is uncharacterized by external testers.
**Worth your time:** Read -- directly relevant if you run Fable 5 workloads and need cost headroom. [Anthropic](https://www.anthropic.com/news/claude-opus-5) · [9to5Mac](https://9to5mac.com/2026/07/24/anthropic-upgrades-claude-with-new-opus-5-model-details-here/)

## Tools worth touching

### OpenAI Codex: voice input and multi-agent coordination (July 24)
- Does: GPT-Live voice control inside Codex and ChatGPT Work desktop app; users can speak to direct multiple parallel agent threads simultaneously; Codex Remote (control Mac/Windows from mobile) moved to GA
- Why now: First voice-to-multi-agent interface in any major coding agent; cuts context-switching friction when managing concurrent agentic tasks
- Try if: You run parallel Codex agents and want hands-free task steering, or want to control a desktop dev environment from your phone
- Skip if: You work primarily in the CLI or IDE extension -- this is desktop-app-first and requires the Work or Codex plan
- Links: [Codex Releasebot](https://releasebot.io/updates/openai/codex) · [explainx.ai summary](https://explainx.ai/blog/openai-codex-july-24-reveal-tibo-sottiaux-teaser-2026)
