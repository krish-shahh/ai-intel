## Tools worth touching

### Claude Plugins Official
- Does: Anthropic's own curated marketplace for [[claude-code]] plugins (MCP servers, slash commands, agents, skills), installed via `/plugin install <name>@claude-plugins-official`.
- Why now: surging on GitHub's daily trending page as the plugin ecosystem consolidates around an official channel instead of scattered gists and forks.
- Try if: you want a vetted distribution path for Claude Code plugins instead of hand-rolling MCP config.
- Skip if: you need Anthropic-level vetting of what a plugin pulls in — the README itself says Anthropic doesn't control the MCP servers or files bundled inside third-party plugins.
- Links: [repo](https://github.com/anthropics/claude-plugins-official)

### scientific-agent-skills
- Does: 163 packaged agent skills (bioinformatics, cheminformatics, clinical research, materials science) for turning a general coding agent into a domain-specific research assistant.
- Why now: trending hard today (+1,587 stars in a day), part of the broader wave of agent-skills packages following Claude's Skills format.
- Try if: you're building a research-agent pipeline in biology, chemistry, or drug discovery and want ready integrations instead of writing tool wrappers from scratch.
- Skip if: you're outside a scientific domain — this is narrowly aimed, not a general dev tool.
- Links: [repo](https://github.com/K-Dense-AI/scientific-agent-skills)

### Workweave Router
- Does: drop-in proxy for Anthropic, OpenAI, and Gemini APIs that scores and routes each request to the cheapest adequate model in under 50ms, claiming 40-70% cost cuts.
- Why now: gaining stars as agentic coding tools multiply and per-request model choice becomes a real cost lever.
- Try if: you're running high-volume agent workloads across multiple providers and want automatic cost-aware routing instead of hardcoding one model.
- Skip if: your traffic is low-volume or single-provider — the self-hosted stack (Postgres, dashboard) isn't worth standing up yet.
- Links: [repo](https://github.com/workweave/router)
