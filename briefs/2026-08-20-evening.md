## Tools worth touching

### Berd
- Does: Apache 2.0 desktop workspace for running AI coding agents across different models and harnesses (Claude Code, Goose, others) through the Agent Client Protocol, storing conversation history locally.
- Why now: Block open-sourced it Aug 18, giving teams a model/harness-agnostic front end instead of locking into one vendor's agent UI.
- Try if: You're juggling multiple coding agents and want one workspace instead of switching apps.
- Skip if: You're already set on a single vendor's CLI or IDE integration and don't need cross-harness switching.
- Links: [GitHub](https://github.com/block/berd) · [VentureBeat](https://venturebeat.com/orchestration/blocks-new-apache-2-0-agent-workspace-berd-works-across-models-and-harnesses-stores-conversation-history-locally)
