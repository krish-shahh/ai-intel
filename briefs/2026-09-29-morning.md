## Tools worth touching

### OpenRig
- Does: combines persistent Claude Code, Codex, and Pi terminal sessions into a multi-agent team where agents message each other directly over tmux instead of relaying through the user.
- Why now: it's trending on GitHub today with the highest star velocity of any coding-agent harness this week, a sign multi-agent coding workflows are maturing past single-session copilot use.
- Try if: you already run Claude Code and Codex side by side and want them coordinating on a shared task instead of copy-pasting between windows.
- Skip if: you need a stable, documented API — it's a fast-moving 0.5.x release with YAML-defined teams still settling.
- Links: [GitHub](https://github.com/mvschwarz/openrig)
