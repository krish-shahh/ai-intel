## Tools & dev

- [[dev-tools]]: Google open-sourced DESIGN.md today - a spec for describing a full design system (tokens + rationale) to coding agents, so they generate consistent UI without being retold each session. Originally internal to Google Stitch. Trending #2 on GitHub with 2,400+ stars. The bet is this becomes "OpenAPI for design." [GitHub](https://github.com/google-labs-code/design.md) · [Google blog](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-design-md/) · [Medium write-up](https://medium.com/design-bootcamp/google-makes-design-md-open-source-on-its-way-to-become-a-industry-standard-16119f2368dd)
