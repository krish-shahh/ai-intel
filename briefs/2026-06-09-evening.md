## Tools & dev

- [[dev-tools]] Apple debuted Siri AI at WWDC 2026 (June 8 keynote): rebuilt using a Gemini-distilled base (Apple insists it is all-Apple code via distillation, not a Gemini integration), standalone app, three-tier routing (device / Private Cloud Compute / Google Cloud on Nvidia B200s), iOS 27, macOS Golden Gate 27. Developer betas live today; EU and China excluded at launch. [Apple Newsroom](https://www.apple.com/newsroom/2026/06/apple-unveils-next-generation-of-apple-intelligence-siri-ai-and-more/) · [TechCrunch](https://techcrunch.com/2026/06/08/wwdc-2026-everything-announced-on-siri-ai-os-27-apple-intelligence-and-more/) · [AppleInsider on Gemini framing](https://appleinsider.com/articles/26/06/08/apples-new-foundation-models-dont-contain-a-drop-of-gemini-as-we-said-they-wouldnt)

[Apple Dev Docs](https://developer.apple.com/documentation/FoundationModels) · [WWDC analysis](https://fourweekmba.com/wwdc-2026-apple-agentic-ai-siri-extensions-builder-pm/)
