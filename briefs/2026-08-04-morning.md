**Evidence:** Terminal-Bench 2.1: 82.7 (vs. V4-Pro-Preview 72.1); DeepSWE: 54.4 (vs. 7.3 Flash Preview); DSBench-FullStack: 68.7 (vs. 37.0); output speed 113.5 t/s on DeepSeek API.
**Caveat:** All benchmarks are DeepSeek's own; no independent third-party evaluation published as of this run.
**Worth your time:** Read.

### Inkling-Small
**Claim:** 276B total / 12B active open-weights multimodal MoE (Apache 2.0); beats its parent model Inkling on every coding and reasoning benchmark.
**Evidence:** SWE-bench Verified 80.2% bash-only harness (Inkling: 77.6%); Terminal-Bench 2.1: 64.7%; HLE text 31.6% (Inkling: 29.7%); full weights on Hugging Face, hosted via Together AI and Fireworks.
**Caveat:** Bash-only SWE-bench harness inflates scores compared to standard scaffolding; no independent replication found yet.
**Worth your time:** Read — Apache 2.0 and 12B active parameters make it genuinely self-hostable for coding agent workflows.

### GPT-5.6 price restructuring
**Claim:** OpenAI cut Luna 80% and Terra 20%, and launched Sol Fast mode (2.5x throughput at 2x cost), effective July 30.
**Evidence:** Official OpenAI pricing page; confirmed by independent reporting.
**Caveat:** None noted.
**Worth your time:** Skim if you route agent workloads across GPT-5.6 variants.

## Tools worth touching

### Panniantong/Agent-Reach
- Does: CLI giving AI agents read/search access to Twitter, Reddit, YouTube, GitHub, Bilibili, XiaoHongShu with no individual API fees
- Why now: 951 stars today; fills the gap for agent-driven research and monitoring without per-platform API keys
- Try if: building agents that need broad web awareness across social and code platforms
- Skip if: scraping third-party platforms creates compliance or ToS risk in your context
- Links: [repo](https://github.com/Panniantong/Agent-Reach)

### huangruiteng/loopx
- Does: State kernel for long-running AI agent teams; manages durable goals, quota-aware auto-wake, and executable todos across restarts
- Why now: 618 stars today; addresses the persistence gap in multi-agent orchestration where most frameworks assume short-lived runs
- Try if: you're running agent loops that need to survive crashes or manage budget across extended tasks
- Skip if: your agents are stateless or single-session
- Links: [repo](https://github.com/huangruiteng/loopx)

### obra/superpowers
