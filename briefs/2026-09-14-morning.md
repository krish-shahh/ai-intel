## Tools worth touching

### colibri
- Does: runs frontier MoE models locally in pure C with zero dependencies.
- Why now: rocketed to the top of GitHub's daily trending (+2,200 stars today) on renewed interest in running big open models without a Python/CUDA stack.
- Try if: you want to serve a large MoE model on hardware you already own without standing up a full inference framework.
- Skip if: you need multi-GPU scaling or production-grade serving; it's a single-machine runtime.
- Links: [repo](https://github.com/JustVugg/colibri)

### agent-skills
- Does: a validated registry of reusable skills for Claude Code, Cursor, Copilot, and Antigravity.
- Why now: as agentic coding tools multiply, a shared, vetted skill format cuts down on copy-pasted prompt scaffolding across them. Relevant to [[claude-code]] and [[agentic-ai]].
- Try if: you maintain custom skills or slash-commands across more than one coding agent and want a common format.
- Skip if: you're on a single tool with its own native skill system already.
- Links: [repo](https://github.com/tech-leads-club/agent-skills)

### open-code-review
- Does: hybrid deterministic-plus-LLM code review with multi-language security detection, from Alibaba.
- Why now: pairs static analysis with LLM judgment to cut false positives; trending today (+1,800 stars).
- Try if: you want automated PR review that goes beyond a bare LLM prompt over the diff.
- Skip if: your CI already has a mature SAST pipeline and you just need a summary layer on top.
- Links: [repo](https://github.com/alibaba/open-code-review)

### Agent-Reach
- Does: gives agents structured browsing access across X, Reddit, YouTube, GitHub, Bilibili, and Xiaohongshu.
- Why now: fills a real gap for agents that need live social/web context beyond a generic search tool; trending today (+640 stars).
- Try if: you're building a research or monitoring agent that needs structured reads of social platforms.
- Skip if: you only need a single-source scraper.
- Links: [repo](https://github.com/Panniantong/Agent-Reach)
