## Tools & dev

- [[claude-code]] A researcher decompiled Claude Code v2.1.196 and found it silently rewrites the date string in its system prompt using Unicode apostrophe swaps and hyphen-to-slash separator changes when ANTHROPIC_BASE_URL matches a hardcoded list of Chinese AI lab keywords (deepseek, moonshot, minimax, zhipu, baichuan, stepfun, 01ai, dashscope, volces). The two keyword lists are stored as base64 strings XOR-decoded with key 91. Suspected purpose: flag and trace distillation pipelines and unauthorized API resellers. Community split: "reasonable anti-distillation defense" versus "malware-adjacent behavior for a dev tool."
