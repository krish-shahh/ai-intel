## Tools worth touching

### NVIDIA SkillSpector
- Does: open-source scanner that checks Claude Code, Codex, and MCP agent skills for vulnerabilities and malicious patterns before you install them, across roughly 70 patterns (prompt injection, data exfiltration, supply-chain risk, system-prompt leakage, tool misuse).
- Why now: trending on GitHub today (19k+ stars, ~600 new); built on research cited in its own docs showing about 26% of a 42,000-skill sample carried at least one vulnerability and 5% showed likely malicious intent.
- Try if: you or your team install third-party Claude Code/Codex skills or plugins with no pre-install vetting step.
- Skip if: you only run skills you wrote yourself or that come from an already-vetted internal registry.
- Links: [GitHub](https://github.com/NVIDIA/SkillSpector) (repo)
