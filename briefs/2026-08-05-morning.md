## The signal

1. OpenAI previews Astra by publishing 10 machine-verified math proofs
   **What happened:** On August 1, OpenAI published ten new results in mathematics and theoretical computer science attributed to an internal model called Astra, each with a machine-checkable Lean 4 certificate; the 249-page manuscript covers non-sofic group constructions, a disproof of Connes's rigidity conjecture, and two Erdős combinatorics problems; total compute cost was roughly $2,000.
   **Why it matters:** Formal verification makes this falsifiable in a way no chatbot benchmark can -- any engineer can download and run the Lean certificates, and if they hold, this is the strongest public evidence yet of genuine novel reasoning at low cost.
   **Confidence:** Confirmed
   **Sources:** [OpenAI](https://openai.com/index/ten-advances-in-mathematics/) (primary) · [The Next Web](https://thenextweb.com/news/openai-astra-model-ten-math-proofs-non-sofic-groups) (independent) · [Gizmodo](https://gizmodo.com/openai-smuggled-the-announcement-of-astra-its-next-ai-model-into-a-blog-post-about-math-2000793689) (independent)

2. OpenAI cuts GPT-5.6 Luna 80% as Chinese models take 46% of US enterprise traffic
   **What happened:** Effective July 30, Luna dropped from $1/$6 to $0.20/$1.20 per million input/output tokens; Terra got a 20% cut; Sol unchanged; OpenAI simultaneously announced 1 billion active users.
   **Why it matters:** A CNBC investigation found Chinese models held 46% of US enterprise token usage on OpenRouter at peak -- this is OpenAI responding with price rather than capability, which signals a structural shift in competitive dynamics.
   **Confidence:** Confirmed
   **Sources:** [OpenAI](https://openai.com/index/advancing-the-price-performance-frontier-with-gpt-5-6/) (primary) · [VentureBeat](https://venturebeat.com/technology/ai-price-wars-openai-cuts-gpt-5-6-luna-prices-by-80-as-model-competition-shifts-toward-cost) (independent) · [gHacks](https://www.ghacks.net/2026/08/04/openai-reaches-one-billion-active-users-and-cuts-gpt-5-6-luna-and-terra-prices-by-up-to-80/) (independent)

3. EU AI Office enforcement powers activated August 2 with no first action yet
   **What happened:** The European AI Office formally gained powers on August 2 to investigate GPAI providers, demand technical documentation, require corrective measures, and issue fines up to €15M or 3% global annual turnover; "technical compliance dialogues" are the stated initial instrument.
   **Why it matters:** Every GPAI provider with EU market exposure now operates under active enforcement authority, not just voluntary obligations -- documentation requests and audits can begin immediately.
   **Confidence:** Confirmed
   **Sources:** [European Commission](https://ec.europa.eu/commission/presscorner/detail/en/ip_26_1714){.bias-center title="Center"} (primary) · [EU Digital Strategy](https://digital-strategy.ec.europa.eu/en/news/commission-starts-enforcing-ai-act-rules-and-new-transparency-requirements-2-august) (primary) · [Help Net Security](https://www.helpnetsecurity.com/2026/08/04/eu-ai-act-enforcement-ai-models/) (independent)

## Tools worth touching

### @cloudflare/computer
- Does: Agent runtime that gives each AI agent a dedicated virtual computer -- file system backed by SQLite, shell execution, Git access -- with dynamic switching between isolates and full Linux containers
- Why now: Released August 3; all operations are gated and audited by default; integrates natively with Cloudflare Workers
- Try if: Building agents that need persistent filesystem state, shell commands, or Git operations in a managed and observable environment
- Skip if: Your agents are stateless or you already manage compute in a self-hosted VM/container
- Links: [repo](https://github.com/cloudflare/computer) · [blog](https://blog.cloudflare.com/cloudflare-computer/) · [changelog](https://developers.cloudflare.com/changelog/post/2026-08-03-cloudflare-computer/)

### TencentCloud/TencentDB-Agent-Memory
- Does: Team-level memory hub for multi-agent systems -- converts conversations, docs, and code into reusable, queryable memory assets shared across agents and sessions
- Why now: Trending #1 on GitHub today (+1,891 stars); addresses the cross-session context sharing problem that most agent frameworks leave to the user
- Try if: Running multi-agent pipelines where agents need to share learned context across sessions
- Skip if: Single-agent workflows or already managing memory with an existing vector store
- Links: [repo](https://github.com/TencentCloud/TencentDB-Agent-Memory)

### airllm
- Does: 70B parameter model inference on a single 4GB GPU via progressive layer offloading -- no quantization required
- Why now: +833 stars today; removes the primary hardware blocker for local 70B-class inference for developers without high-VRAM machines
- Try if: You want 70B output quality locally and can tolerate slow generation speed
- Skip if: Latency is a constraint -- offloading is slow; quantized models are faster for production
- Links: [repo](https://github.com/lyogavin/airllm)
