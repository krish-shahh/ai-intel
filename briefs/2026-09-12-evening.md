## Tools worth touching

### Superpowers
- Does: A composable skill library that walks coding agents (Claude Code, Cursor, Devin, Copilot CLI, Gemini, Kimi Code) through a full dev cycle: design review, planning, TDD, systematic debugging, code review.
- Why now: Gained 729 stars in a day as teams look for a repeatable agent workflow instead of ad hoc prompting.
- Try if: You run agents on non-trivial codebases and want a standard planning/TDD/review loop.
- Skip if: You already have an internal skill library covering the same ground.
- Links: [repo](https://github.com/obra/superpowers)

### i-have-adhd
- Does: A coding-agent output skill that forces terse, action-first responses instead of long preambles.
- Why now: Picked up 3,463 stars in a single day, the sharpest jump on GitHub trending today, a sign a lot of people share the same complaint about buried answers.
- Try if: You're tired of agent responses that bury the actual fix under paragraphs of hedging.
- Skip if: You want the agent's reasoning shown inline rather than jumping straight to the answer.
- Links: [repo](https://github.com/ayghri/i-have-adhd)

### garak
- Does: Open-source LLM vulnerability scanner from [[nvidia]] that probes for prompt injection, jailbreaks, data leakage, hallucination, and toxicity, nmap-style.
- Why now: Actively maintained (4,600+ commits) and trending today as more teams need a baseline red-team pass before shipping agents.
- Try if: You're shipping an LLM-backed product and want an automated first-pass security check.
- Skip if: You need managed, compliance-grade audit reporting, not a scanning engine.
- Links: [repo](https://github.com/NVIDIA/garak)
