## Tools worth touching

### needle
- Does: 14MB foundation model built to run on phones, wearables, smart home devices, and robots.
- Why now: +364 stars today; pushes the "foundation model" label down to hardware that can't run even small local LLMs today.
- Try if: You're shipping on-device inference for hardware with single-digit-MB memory budgets.
- Skip if: You just need a small quantized LLM — this trades general capability for footprint.
- Links: [GitHub](https://github.com/cactus-compute/needle)

### OpenViking
- Does: Self-evolving context database unifying agent memory, knowledge/RAG, and skills in one store.
- Why now: +213 stars today; targets the same cross-session memory gap that's driven several similar tools onto trending this week.
- Try if: You're building a long-running agent and juggling separate memory, RAG, and skill stores today.
- Skip if: Your agent is stateless or short-lived enough that a vector store already covers you.
- Links: [GitHub](https://github.com/volcengine/OpenViking)
