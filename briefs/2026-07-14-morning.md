TL;DR
Claude Code shipped v2.1.208+v2.1.209 today with screen-reader support and a wave of agent reliability fixes. Gemini 3.5 Pro is targeting Thursday July 17 after a full architectural rebuild, but no official Google confirmation exists yet.

## Tools & dev

- [[claude-code]] v2.1.208 (July 14, 01:10 UTC, 45 changes): screen reader mode (`--ax-screen-reader` or `CLAUDE_AX_SCREEN_READER=1`), `vimInsertModeRemaps` setting for jj-to-Esc sequences, `CLAUDE_CODE_PROCESS_WRAPPER` env var for corporate launcher support, mouse-click support for multi-select menus in fullscreen, fixed fast mode not auto-restoring after model switches, fixed background agent replies lost on delivery failure, fixed context window briefly resetting after CLI auto-updates, fixed HTTP/2 in supervised/background sessions, paginated 200+ row markdown tables, fixed several Bedrock streaming and OAuth MCP server bugs. v2.1.209 hotfix followed six hours later, unblocking `/model` and other dialogs that were incorrectly blocked in background sessions. [GitHub releases](https://github.com/anthropics/claude-code/releases)

## Models & research

- [[model-releases]] Gemini 3.5 Pro is targeting July 17 GA per third-party reporting — Google rebuilt the architecture from scratch rather than shipping what it had, adding a claimed 2M-token context window and a reasoning layer to compete with Fable 5 and GPT-5.6. As of July 13, no official model card, pricing page, or Gemini API listing exists; every specific claim comes from unnamed sources. DeepSeek V4 also goes from preview to stable on July 17, and the legacy `deepseek-chat`/`deepseek-reasoner` API aliases hard-retire July 24 — requests using old names will error after that. [TechTimes (July 13)](https://www.techtimes.com/articles/320308/20260713/gemini-35-pro-targets-july-17-after-full-rebuild-every-spec-remains-unconfirmed.htm) · [DEV.to DeepSeek migration guide](https://dev.to/agdex_ai/deepseek-v4-api-migration-guide-everything-before-the-july-24-2026-deadline-4m30)

- **cactus-compute/needle** — 26M-param function-call model designed to run on phones, watches, and glasses; distilled from Gemini using an MLP-free "Simple Attention Network" architecture (MLPs dropped entirely, relying on external tool lists instead). Achieves 6,000 tokens/sec prefill and outperforms FunctionGemma-270m on single-shot function calling. Weights fully open-source. [GitHub](https://github.com/cactus-compute/needle)
