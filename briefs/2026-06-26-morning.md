- [[ai-research]] [[natolambert]] and Ai2 released TMax (arXiv 2606.23321, June 22): open RL recipe for terminal agents, ships 9B and 27B weights plus training data and code. TMax-27B scores 42.7% on Terminal-Bench 2.0, currently the best among public models. Core insight: combining difficulty control, personas, and verifier diversification to generate terminal environments cheaply for RL and SFT. [arXiv](https://arxiv.org/abs/2606.23321) · [Lambert on X](https://x.com/natolambert/status/2069055254961021150) · [Substack](https://natolambert.substack.com/p/tmax-an-open-rl-recipe-for-terminal)

## Tools & dev

- [[agentic-ai]] Anthropic told the Senate Banking Committee on June 25 that Alibaba-linked entities ran the largest known distillation attack against Claude: 28.8M exchanges through nearly 25K fraudulent accounts between April 22 and June 5, targeting agentic reasoning, software engineering, and long-horizon planning capabilities. Anthropic is urging export control expansion, mandatory screening of high-volume API usage, and penalties for model extraction campaigns. The Senate letter (dated June 10) was what triggered the June 12 US export-control directive suspending Fable 5 and Mythos 5. [CNBC](https://www.cnbc.com/2026/06/24/anthropic-alibaba-distillation-campaign.html) · [TechTimes](https://www.techtimes.com/articles/319105/20260625/alibaba-ran-largest-known-ai-theft-campaign-against-claude-anthropic-tells-senate.htm) · [Slashdot](https://yro.slashdot.org/story/26/06/25/1810226/anthropic-says-alibaba-must-be-punished-for-largest-claude-cloning-attack) · [The Next Web](https://thenextweb.com/news/anthropic-accuses-alibaba-distillation-claude-qwen)

## OSS

- [[oss]] [[dev-tools]] google-labs-code/design.md is today's #1 GitHub trending repo (2,319 stars today, 20.6K total). It is Google Labs' open spec for a DESIGN.md file: a markdown contract with YAML frontmatter for design tokens (colors, type, spacing, components) plus human-readable rationale, so any coding agent can generate on-brand UI without per-session re-explanation. Works with Stitch, Claude, and others; ships with a WCAG AA linter. Apache 2.0. [GitHub](https://github.com/google-labs-code/design.md) · [Google Labs blog](https://blog.google/innovation-and-ai/models-and-research/google-labs/stitch-design-md/)
