## Models & research

### DeepSeek-V4-Flash-0731
**Claim:** Re-post-trained flash model surpasses V4-Pro-Preview on all nine published agent/coding benchmarks with the same architecture.
**Evidence:** DeepSeek's own API changelog (primary). Artificial Analysis confirms the SWE-bench Verified score of 79% at $0.28/M output. Terminal Bench 2.1: 82.7 vs V4-Pro-Preview's 72.1. DSBench-FullStack: 68.7 vs 37.0. Toolathlon: 70.3, Cybergym: 76.7. DeepSWE: 54.4 -- vendor-run only, harness release "coming soon."
**Caveat:** DeepSWE is self-reported using DeepSeek's own harness, not yet reproducible by third parties. The API now supports the Responses format and is Codex-compatible, but the web/app interface is not yet updated. V4-Pro official release still pending.
**Worth your time:** Read if you're benchmarking agentic or coding pipelines; the cost/performance gap with frontier closed-model pricing is now very wide.

## Tools worth touching

### MCP 2026-07-28 specification
- Does: moves the Model Context Protocol to a stateless request/response core, aligns authorization with OAuth 2.1 / OIDC, and ships a versioned extensions framework for MCP Apps and Tasks.
- Why now: Anthropic has shipped Claude support for this spec; remote MCP servers no longer need sticky sessions, shared session stores, or deep packet inspection -- plain round-robin load balancers now work. Enterprise identity systems (Entra, Okta) connect without workarounds.
- Try if: you run or plan to run production MCP servers at scale, or maintain Claude integrations with enterprise auth requirements.
- Skip if: you only use local MCP servers over stdio -- the session management change is a network transport concern.
- Links: [MCP spec changelog](https://modelcontextprotocol.io/specification/2026-07-28/changelog) · [Anthropic blog](https://claude.com/blog/bringing-mcp-2026-07-28-to-claude) · [AWS AgentCore support](https://aws.amazon.com/blogs/machine-learning/how-agentcore-gateway-supports-the-mcp-2026-07-28-spec/) · [Migration guide](https://www.digitalapplied.com/blog/mcp-2026-07-28-spec-stateless-migration-guide)
