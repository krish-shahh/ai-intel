TL;DR
Alibaba's Claude Code ban took effect today after the steganographic backdoor story landed on China's NVDB. Anthropic also reset all Code usage limits following a rough week of outages and launched Reflect, a usage-analytics dashboard.

## Models & research

- [[model-releases]] Grok 4.5 first-day assessment: hallucination rate climbed from 25% to 54%, making it a cost leader at $2.49/coding task vs Claude Code's $11.80, but unreliable for factual or high-stakes work. Artificial Analysis ranks it 4th on Intelligence Index behind Fable 5, GPT-5.5, and Opus 4.8. EU users locked out of API and app due to regulatory hold. [TechTimes](https://www.techtimes.com/articles/320038/20260709/grok-45-cuts-coding-agent-cost-80-near-frontier-speed-higher-hallucinations.htm) · [Artificial Analysis](https://artificialanalysis.ai/articles/grok-4-5-brings-spacexai-to-the-the-intelligence-frontier)

## Tools & dev

- [[claude-code]] Anthropic reset 5-hour and weekly limits for all users today following outages on July 3, 6, and 8 (including a two-hour degradation of Claude Code on the web, Cowork Remote, Claude Tag, and claude.ai on July 8). A temporary 50% weekly limit boost is due to expire July 13. [Winzheng](https://www.winzheng.com/en/article/anthropic-claude-usage-limit-reset-subagent-fix)

- Anthropic launched Reflect in Claude: a Spotify Wrapped-style usage dashboard showing topics, session frequency, and time spent over 1/3/6/12-month windows. Includes quiet hours, break nudges, and mindful-use prompts. Beta for Free/Pro/Max users with memory on. [Anthropic](https://www.anthropic.com/news/reflect-with-claude) · [Dataconomy](https://dataconomy.com/2026/07/10/claude-gets-reflect-dashboard-to-track-ai-usage/) · [TNW](https://thenextweb.com/news/anthropic-claude-reflect-wrapped-usage-dashboard)

- [[agentic-ai]] Claude Cowork expanded to mobile and web (rolling out to Max subscribers from July 8-9). Sessions run remotely so work continues when the device is offline; scheduled tasks fire with no device active. Anthropic says more than 90% of Cowork usage is non-software work: business operations, reports, and spreadsheets. Doubled usage limits extended through Aug 5. [TechCrunch](https://techcrunch.com/2026/07/07/the-coding-agent-wars-are-spilling-into-the-rest-of-the-office-claude-cowork/) · [9to5Mac](https://9to5mac.com/2026/07/07/anthropic-expanding-claude-cowork-to-mobile-and-web-details-here/)

- [[agentic-ai]] OpenAI launched ChatGPT Work on July 9: an agentic workspace mode that operates across connected apps, files, email, and desktop for hours, delivering finished deliverables from a single prompt. Available on desktop now for all plans; web and mobile rolling out to paid tiers this week. Direct answer to Claude Cowork. [SiliconANGLE](https://siliconangle.com/2026/07/09/openai-debuts-chatgpt-work-agentic-tool-automating-business-workflows/) · [Forbes](https://www.forbes.com/sites/madhulika-pathak/2026/07/09/openai-debuts-chatgpt-work-workplace-ai-agent-with-gpt-56/) · [BNN Bloomberg](https://www.bnnbloomberg.ca/business/artificial-intelligence/2026/07/09/openai-launches-chatgpt-work/)

## OSS

- **TencentCloud/TencentDB-Agent-Memory** — fully local 4-tier memory pipeline for AI agents (L0 raw dialogue → L1 atomic facts → L2 scenes → L3 user persona), backed by SQLite with no external APIs. Cuts token usage by 61% and raises PersonaMem accuracy from 48% to 76% in tests with OpenClaw. Surging today with +581 stars. [GitHub](https://github.com/TencentCloud/TencentDB-Agent-Memory)

## Other

- Alibaba's ban on Claude Code and all Anthropic model products (Sonnet, Opus, Fable) took effect today; employees directed to switch to in-house Qoder. Trigger: security researchers found Claude Code versions 2.1.91–2.1.197 (April–July 1) embedded XOR-obfuscated steganographic markers in system prompt date strings to flag users from Chinese timezones and proxies. China's NVDB issued a formal security alert on July 8. Anthropic called it an anti-abuse experiment and removed it in v2.1.198 on July 1. [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence/alibaba-bans-anthropics-claude-code-after-an-alleged-hidden-china-detection-backdoor-is-uncovered-employees-told-to-switch-to-qoder-as-the-rift-between-the-firms-widens) · [BigGo](https://finance.biggo.com/news/a401b1c7-07f5-44e1-9291-cbbd71da342c) · [The Register](https://www.theregister.com/security/2026/07/08/china-ditch-older-claude-versions-with-backdoor-code/5268371)
