## Tools worth touching

### SkillSpector
- Does: static + LLM-based security scanner for AI agent skills (Claude Code, Codex CLI, etc.) that flags prompt injection, data exfiltration, privilege escalation, and other risks before you install one.
- Why now: built by NVIDIA, citing internal research that ~26% of published agent skills contain a vulnerability and ~5% show likely malicious intent — a hardware vendor moving into agent-skill supply chain security.
- Try if: your team installs third-party Claude Code or Codex skills and wants a pre-install gate instead of trusting the README.
- Skip if: you only run skills you wrote yourself.
- Links: [repo](https://github.com/NVIDIA/SkillSpector)

### awesome-design-md
- Does: a curated set of 73 DESIGN.md files pulled from real product design systems (Stripe, Vercel, Tesla, and others) that you drop into a repo so a coding agent matches that brand's visual language.
- Why now: plain markdown as a design-spec format for agents is catching on as an alternative to Figma exports, and this collection just crossed a large star count.
- Try if: you're using Claude Code or similar to scaffold UI and want a real starting design language instead of generic defaults.
- Skip if: you already maintain your own design tokens or style guide.
- Links: [repo](https://github.com/VoltAgent/awesome-design-md)

### video-use
- Does: edit raw video footage by chatting with a coding agent — cuts filler words and dead air, color-grades, burns subtitles, outputs a final.mp4.
- Why now: reads word-level transcripts instead of watching frames, so it stays token-cheap; extends the browser-use team's agent approach to a media workflow it wasn't built for.
- Try if: you produce short clips regularly and want a scriptable rough cut instead of a GUI editor.
- Skip if: you need frame-accurate professional editing — this is rough-cut automation, not an NLE replacement.
- Links: [repo](https://github.com/browser-use/video-use)
