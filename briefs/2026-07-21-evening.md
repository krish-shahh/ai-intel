## Tools & dev

- **Hugging Face breach (July 16 / follow-up July 20)**: An autonomous AI agent exploited two code-execution paths in Hugging Face's dataset-processing pipeline, escalated to node level, harvested cloud credentials, and moved laterally -- all via a malicious dataset. Thousands of individual actions across a swarm of short-lived sandboxes. No public models or Spaces tampered. Credentials rotated, affected nodes rebuilt. This is the first confirmed agentic supply-chain attack on a major ML platform. [BleepingComputer](https://www.bleepingcomputer.com/news/security/hugging-face-breach-autonomous-ai-agent-system-internal-datasets-credentials/) · [HuggingFace blog](https://huggingface.co/blog/security-incident-july-2026) · [Axios](https://www.axios.com/2026/07/20/hugging-face-ai-cyberattack-data-breach)
- **1Password + Claude (July 16)**: Agents can now log into websites using stored credentials without the model ever seeing the password. User confirms via biometrics, 1Password injects directly into the page. Per-session/per-task scoping, no standing access. Mac only for now, requires Claude desktop + Chrome extension + 1Password. Solves a real agentic browser-use security problem. [1password.com](https://1password.com/blog/1password-for-claude)
- **[[claude-code]] /fork update (July 17)**: `/fork` copies your conversation into a new background session while you keep working; `/subtask` replaces the old in-session subagent. WebSearch cap at 200 calls/session. Subagent spawn cap at 200/session. Tighter Bash/MCP execution safeguards. [Releasebot](https://releasebot.io/updates/anthropic/claude-code)
- **Ollama v0.32.1 (July 16)**: Flash attention enabled for NVIDIA compute capability 6.x GPUs, iGPU vision offload with padding, Gemma 4 tool-call multi-turn fix, MLX cache leak patched. [localaimaster.com](https://localaimaster.com/blog/ollama-version-history)
