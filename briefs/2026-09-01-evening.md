### ECC
- Does: agent harness layer that bolts 68 specialized subagents, 286 reusable skills, and security scanning (AgentShield) onto [[claude-code]], [[codex]], [[opencode]], and Cursor.
- Why now: trending on GitHub today (245k stars, +512 today), now sponsored by CodeRabbit, Greptile, and Atlas Cloud, with cross-harness support past v2.
- Try if: you run coding agents across a team and want a packaged review/security/TDD skill set instead of hand-rolling your own subagents.
- Skip if: you're on a solo project — 286 skills is overkill when you need one or two commands.
- Links: [repo](https://github.com/affaan-m/ECC)
