## Tools & dev

- [[claude-code]] Claude Code 2.1.183 shipped June 19; the main safety change is auto mode now blocks destructive git commands when the user did not ask to discard local work. [Claude Code changelog](https://code.claude.com/docs/en/changelog)

- [[codex]] OpenAI Codex added Record & Replay for macOS today: record a workflow once and Codex converts it into a reusable "skill" via Computer Use; excluded from EEA, UK, and Switzerland at launch. [Codex changelog](https://developers.openai.com/codex/changelog) · [Digg](https://digg.com/tech/0zh4o6hw)

[Developers Digest](https://www.developersdigest.tech/blog/opencode-developer-guide-2026)

## OSS

- `headroom` (chopratejas/headroom) is the #1 Python repo on GitHub trending today (+3,938 stars); compresses tool outputs, logs, and RAG chunks 60-95% before they hit the LLM with no measurable quality loss, and ships as a library, proxy, or MCP server. [GitHub](https://github.com/chopratejas/headroom)

- `codebase-memory-mcp` (DeusData) also trending today (+1,055 stars); indexes a codebase into a persistent knowledge graph with 158-language support and sub-millisecond queries, claiming 99% fewer tokens vs naive retrieval. [GitHub trending](https://github.com/trending)
