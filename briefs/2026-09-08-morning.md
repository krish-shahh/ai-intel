## Tools worth touching

### Context Mode
- Does: cuts AI coding-agent context usage by sandboxing tool output (claims a 315KB dump shrinks to 5.4KB), logging session state to SQLite with full-text search so compaction restores state instead of re-dumping raw data, and having the model write analysis scripts instead of reading whole files.
- Why now: hit GitHub's daily trending page today with 650+ new stars, part of the broader fight against context-window bloat in long agentic coding sessions.
- Try if: you run Claude Code, Cursor, or another agent against a large repo and keep hitting context blowups or losing state across compaction.
- Skip if: your sessions are short enough that context limits aren't biting yet.
- Links: [mksglu/context-mode](https://github.com/mksglu/context-mode) ([[dev-tools]])
