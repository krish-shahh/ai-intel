## Models & research

### Claude Opus 5
**Claim:** Beats Fable 5 on FrontierBench v0.1 (43.3% vs 33.7%), wins on 8/13 benchmarks, triples ARC-AGI 3 scores, matches Fable 5 within 0.5% on CursorBench 3.2 -- at $5/$25 per MTok vs Fable 5's $10/$50. Knowledge cutoff May 2026. Anthropic calls it their most aligned model with lowest measured deceptive-behavior rates.
**Evidence:** All benchmark figures are Anthropic-published. Model is live and testable via API. No third-party replication of FrontierBench results yet. CursorBench 3.2 gap of 0.5% is within noise for most workloads.
**Caveat:** Every number is a company claim. FrontierBench v0.1 is a new, Anthropic-designed benchmark -- wait for independent eval before restructuring pricing tiers around it. The deceptive-behavior claim is unverifiable without an external safety audit.
**Worth your time:** Read. If FrontierBench holds under independent replication, this is the default pick for agentic pipelines. [Anthropic announcement](https://www.anthropic.com/news/claude-opus-5) · [TechCrunch](https://techcrunch.com/2026/07/24/anthropic-launches-opus-5/)

### Kimi K3 (open weights tonight)
**Claim:** 2.8T-parameter MoE, 16-of-896 experts, 1M context, native vision, MXFP4 quantization. Weights release at July 27 00:00 UTC (~1.4TB download). Ranked #3 on Artificial Analysis behind Fable 5 and GPT-5.6 Sol.
**Evidence:** API live since July 16; Artificial Analysis leaderboard (independent). [[natolambert]] writes the open-weights gap has narrowed to "3-5 months" from the prior "6-9 months" estimate. [interconnects.ai](https://www.interconnects.ai/p/kimi-k3-the-open-weights-escalation)
**Caveat:** Artificial Analysis independently measured 51% hallucination rate -- up 12 points from K2.6 -- which Moonshot omits from its charts. An April 2026 cross-user data breach (disclosed, never publicly addressed) and Chinese National Intelligence Law obligations apply regardless of Singapore incorporation. MXFP4 quantization needs nonstandard inference setups (standard llama.cpp/vLLM may need patches).
**Worth your time:** Read. Largest open-weight release ever if it lands tonight. Monitor HuggingFace for actual drop and watch community hallucination benchmarks before deploying. [TechTimes caveat](https://www.techtimes.com/articles/321499/20260724/kimi-k3-open-weights-drop-july-27-near-frontier-coding-undisclosed-hallucination-risk.htm) · [Kimi blog](https://www.kimi.com/blog/kimi-k3)

## Tools worth touching

### alibaba/open-code-review
- Does: Hybrid AI code reviewer -- deterministic pipelines plus LLM agent for line-level comments, built-in rulesets for NPE, thread safety, XSS, SQL injection; reads full file context via tool use
- Why now: Alibaba open-sourced the internal tool it ran at scale (10k+ employees, 1M+ defects caught); trending with 840 stars today and now compatible with Anthropic and OpenAI APIs
- Try if: You want structured, reproducible code review with explicit rule sets rather than a free-form LLM pass -- especially on large Java/Go codebases
- Skip if: Your codebase is small enough that an unstructured LLM pass works fine; Go dependency is a barrier
- Links: [github.com/alibaba/open-code-review](https://github.com/alibaba/open-code-review) · [GIGAZINE writeup](https://gigazine.net/gsc_news/en/20260607-open-code-review/)

### ego-lite
- Does: Lightweight browser built for AI agents to execute web tasks; supports session-sharing with Claude Code without disrupting the user's active session
- Why now: 898 stars today on GitHub trending; purpose-built for the agent-browser integration problem that most Claude Code workflows still solve with Playwright hacks
- Try if: You run Claude Code workflows that need to drive a browser without blocking your own work
- Skip if: Your agent workflows don't touch a browser; Playwright headless already covers your use case
- Links: [github.com/citrolabs/ego-lite](https://github.com/citrolabs/ego-lite)
