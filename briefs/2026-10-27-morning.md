## The signal

## Tools worth touching

### obra/superpowers
- Does: an agentic-skills framework and software-development methodology built for Claude Code.
- Why now: turns the "skills" pattern Claude Code shipped with into a repeatable team methodology instead of ad hoc prompt libraries.
- Try if: you're standardizing how a team writes and shares Claude Code skills.
- Skip if: you just need one-off prompts, not a methodology.
- Links: [repo](https://github.com/obra/superpowers)

### NVIDIA/SkillSpector
- Does: a static and behavioral scanner that checks installable AI-agent skills for prompt-injection and supply-chain risk.
- Why now: agent skill marketplaces (Claude Code and others) are growing fast with little vetting; this is a first dedicated scanner for that specific risk class.
- Try if: you install third-party skills or plugins into agent tools and want an automated check before you do.
- Skip if: you only write and run your own skills in a closed environment.
- Links: [repo](https://github.com/NVIDIA/SkillSpector)

### Nutlope/hallmark
- Does: a shared "design taste" skill that stops coding agents (Claude Code, Cursor, Codex) from producing generic-looking UI.
- Why now: targets a well-known, recurring failure mode of agent-generated frontend code.
- Try if: you're shipping UI output from a coding agent and tired of fixing the same generic look every time.
- Skip if: your agent output is backend-only or you already enforce a strict design system.
- Links: [repo](https://github.com/Nutlope/hallmark)
