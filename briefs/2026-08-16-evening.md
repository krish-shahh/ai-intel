## Models & research

### Qwen3.8-27B
**Claim:** Dense 27.78B multimodal model, Apache 2.0, 262k-token context; OSWorld-Verified 84.3 (Muse Spark 1.1: 87.1), DeepSWE v1.1 42.2, Terminal-Bench 2.1 73.0, SWE-Bench Pro 61.7.
**Evidence:** Weights confirmed on HuggingFace under Qwen/Qwen3.8-27B. Multiple independent trackers confirm benchmarks; no third-party reproduction of OSWorld score yet.
**Caveat:** All benchmarks are Alibaba's own numbers. OSWorld-Verified gains are large enough that independent confirmation matters before treating 84.3 as settled.
**Worth your time:** Read if you run local computer-use or coding agents — this is the current ceiling at 24GB VRAM.

### Needle 2 (Cactus Compute)
**Claim:** 45M-parameter tool-calling model shipped as a 14MB binary; runs a full session in 28MB of RAM. Decode throughput: 500 tok/s on Raspberry Pi 5, 300-700 tok/s on sub-$200 phones. Competes with FunctionGemma 270M and Apple FM on tool-call accuracy at 5-70x smaller size.
**Evidence:** Open release via GitHub; MarkTechPost confirms the launch and cited throughput figures. Binary size and RAM floor are independently checkable.
**Caveat:** Scope is narrow by design — structured tool-call extraction only, no open-ended prose. Benchmark comparisons are Cactus's own; the model trades every generalist capability for size.
**Worth your time:** Read if you build on-device or embedded agentic workflows; Ignore otherwise.
Sources: [cactuscompute.com](https://cactuscompute.com/needle) (primary) · [GitHub](https://github.com/cactus-compute/needle) (primary) · [MarkTechPost](https://www.marktechpost.com/2026/08/13/cactus-compute-needle-2-45m-parameter-tool-calling-model/) (independent)

## Tools worth touching

### Soup v3 (MakazhanAlpamys/Soup)
- Does: LoRA fine-tunes any 8B-class LLM from a single YAML file using layer streaming — copies one decoder layer at a time into VRAM, bounding peak to ~3.32GB
- Why now: v3 (Aug 13) demonstrated Llama-3.1-8B training on an RTX 3050 4GB laptop GPU at 119.6 tok/s — largest published result for this hardware class, up from prior best of 1.3B
- Try if: You want to fine-tune a model on a machine without a data-center GPU or you are constrained to a consumer laptop
- Skip if: You already run unsloth or axolotl on a proper server — this trades throughput for VRAM efficiency
- Links: [GitHub](https://github.com/MakazhanAlpamys/Soup) · [Gigazine write-up](https://gigazine.net/gsc_news/en/20260806-soup-fine-tune-llm/) · [PyPI](https://pypi.org/project/soup-cli/)

### cactus-compute/needle
- Does: 14MB binary that maps natural-language sentences to typed function signatures; tool-calling only, no prose
- Why now: The smallest published model that holds competitive tool-call accuracy against models 5-70x larger; ships with no runtime install
- Try if: You build on-device agentic pipelines for phones, wearables, or Raspberry Pi and can't afford the RAM footprint of even a quantized 1B
- Skip if: You need any capability beyond structured tool dispatch
- Links: [GitHub](https://github.com/cactus-compute/needle) · [HuggingFace](https://huggingface.co/Cactus-Compute/needle2) · [product page](https://cactuscompute.com/needle)
