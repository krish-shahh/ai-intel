## Tools worth touching

### vercel-labs/agent-desktop + agent-browser
- Does: a pair of CLIs from Vercel Labs for AI agents — one for general computer use, one for browser automation specifically.
- Why now: agent-desktop pulled 2,173 stars in a day, the top new agent-tooling repo on GitHub trending; shipped alongside agent-browser the same day.
- Try if: you're wiring an agent to drive a real desktop or browser session instead of a sandboxed API.
- Skip if: your agent only needs headless HTTP/API access — this is overhead you don't need.
- Links: [agent-desktop](https://github.com/vercel-labs/agent-desktop) · [agent-browser](https://github.com/vercel-labs/agent-browser)

### max-sixty/worktrunk
- Does: a git worktree manager built for running multiple AI coding agents in parallel.
- Why now: +546 stars today, direct response to the now-common pattern of running several Claude Code/Codex sessions against the same repo at once.
- Try if: you're juggling worktrees by hand for parallel agent runs and it's gotten unwieldy.
- Skip if: you only run one agent session at a time.
- Links: [repo](https://github.com/max-sixty/worktrunk)
