## Tools worth touching

### Claude Code Mods
- Does: lets you write TypeScript functions that hook into [[claude-code]] internals to rewrite prompts, block or retry tool calls, redact secrets, or swap out built-in features.
- Why now: core features like `/diff` now ship as mods themselves, so this is the real extension point, not a side API.
- Try if: you want to enforce a house policy (secret redaction, custom retry logic) across a team's Claude Code setup.
- Skip if: you'd install a mod from an untrusted source — Anthropic is explicit that mods are not sandboxed.
- Links: [Anthropic blog](https://claude.com/blog/claude-code-mods) · [The New Stack writeup](https://thenewstack.io/anthropic-claude-code-mods-plugins/)
